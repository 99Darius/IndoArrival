# Lessons

- 2026-11-05 A form's public JavaScript bundle holds its exact error messages and field rules (Thailand: `assets/bundle/*/en.json` and validators; Indonesia: the Vite bundle). Reading them gives guides real wording and rules that clones and listicles don't have, with no form submission. [candidate-general]
- 2026-11-05 `moat analytics-new` only verifies Search Console by DNS TXT, and stores `sc-domain:`. A site on a shared host such as `*.vercel.app` can't do DNS, so the stored GSC_SITE_URL is wrong until a URL-prefix property or own domain is set. [candidate-general]
- 2026-11-05 `moat-init` appends the catalog to AGENTS.md and `venture-register` enrols HQ pushes by default. In a public repo both would publish internal detail, including a person's email and weekly cross-venture advice. Public repos need a short pointer and `--no-hq-push`. [candidate-general]
