All Indonesia arrival card not working: causes and fixes

Checked 5 November 2026 by Darius Cheung. Independent guide, not a government website.

Short answer

If the form rejects you with a clear message, it's usually the passport type, an expired passport or a blank required field. If it fails with a technical message, such as an authentication error, the fault is on the server: your entries aren't the cause, so try again later rather than changing them. Allow time before your flight, as the government says it doesn't guarantee uninterrupted access.

Messages the form can show

These come from the site's own code. We can't always tell exactly when each appears, but the wording usually points to the fix.

MessageWhat to do
"This passport has expired. Please use a passport that is still valid to continue."Check the expiry date you typed. If it's truly expired, you need a new passport before you can file or travel.
"The passport submitted does not indicate Indonesian citizenship. Please ensure you are using the correct application form for foreign visitor."Go back and choose Foreign Visitor.
"The submitted passport shows Indonesian citizenship. Make sure you use the correct application form for Indonesian citizens."The reverse. Use the citizens' form, or check the nationality you selected.
"Please confirm your visa first to proceed with the next process."Complete the visa step. In a group, each member's visa needs confirming.
"The limit for group arrival applications is only 10 travellers."Split a large party. See the group guide.
"Please review your form again."A field is incomplete or wrong. Scroll back through each section.
"Make sure that the passport photo is in landscape format."Rotate or retake the picture. The site mentions a 2 MB file limit on uploads.
"Request failed with status code ..."A failed connection to the server. Retry later.

The authentication error people report

Reader comments on one travel blog describe the form stopping at submission with an authentication failure mentioning SCRAM-SHA-256. That's a database login term, so it points to a fault on the server's side, not with your browser or your answers. Commenters guessed the same. We found no official statement about it.

If you see something like this, changing browsers probably won't help. Wait and try again later, and save your details somewhere handy so a retry doesn't mean searching for them again.

Things to try for an ordinary failure

  1. Make sure you're on allindonesia.imigrasi.go.id. A different address may be a copy.
  2. Check you're within 72 hours of arrival. One guide reports that a card submitted too early means completing a new one in the window.
  3. Fill every required field. Guides report blank fields such as flight number, Indonesian address or the declarations blocking submission.
  4. Reload, or use a different browser or device. Avoid page translation while filling the form, as it can make a page behave oddly.

"My card was charged but the site says failed"

A traveller on the same blog reported this. Note that the arrival card itself is free, so a payment page for it is a warning sign about which site you're on. A visa on arrival is different: it is paid, and the official site handles that too, so check which one you were paying for. Either way, contact your bank with the details.

If it still won't work

Sources differ on this. Some say travellers who haven't completed the card can still enter, and others stress that you'll be asked for proof. Plan to have your QR code, and if the system truly fails, keep a screenshot of the error and ask staff on arrival. The site points to a call centre for help without listing a number we can verify, so check its help page.

Questions people ask

Can I fill in the All Indonesia form at the airport?

Travellers have asked this and reports differ. Treat it as a fallback rather than a plan, and expect queues.

Why does the form reject a passport I've used before?

Check the expiry date you typed and which form you're on. The site also says to use the same passport as for other immigration applications, which matters if you've renewed since applying for a visa.

Is the site down right now?

We don't monitor it. If the same technical error appears on two networks and devices, assume the server is at fault and try later.
