- [P2] Merge each tab's changes before replacing the recording draft — /Users/dariuscheung/Downloads/Antigravity/IndoArrival/extension/src/content/th/recorder.ts:110-113
  When Thailand's form is open in two tabs during recording, each tab writes its entire captured snapshot over `draft.fields`. If both tabs edit the same field, `applyDraft` deliberately preserves each tab's locally changed value; a later edit to an unrelated field can therefore silently restore an older answer from that tab. Read and merge only the pending changes through a serialized background operation so unrelated edits cannot overwrite newer answers.
