Full review comments:

- [P2] Track cleared answers per field before the delayed refresh — /Users/dariuscheung/Downloads/Antigravity/IndoArrival/extension/src/content/th/recorder.ts:49-51
  If a traveller clears two filled fields within the 250 ms delay, only the last field is forgotten. `refresh()` marks an empty answer as cleared only when its key equals `lastKey`, so the earlier field retains its old saved value and Fill restores it next time. Capture each field's cleared state when it changes rather than relying on one shared last-touched key.

- [P2] Reject overlapping fills for different travellers — /Users/dariuscheung/Downloads/Antigravity/IndoArrival/extension/src/content/th/fill.ts:151-152
  If Fill is running for traveller A and the user selects B in the popup and presses Fill, this returns A's running promise without filling B's answers. B's caller then emits `REPLAYED` with B's ID, so later manual corrections to A's form can be saved under B. Reject an overlapping request or queue its own replay instead of treating the first replay as completion of both requests.
